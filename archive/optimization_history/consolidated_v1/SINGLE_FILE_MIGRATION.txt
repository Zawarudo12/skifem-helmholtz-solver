Single-file solver migration v1

Purpose
- Consolidates the active photonics_fem physics/numerics into photonics_fem_solver.py.
- Does not intentionally optimize or alter the numerical method yet.
- Keeps geometry builders and experiment runners separate.

Files
- photonics_fem_solver.py: consolidated solver core
- run_objectives_1_2.py: imports changed only
- run_objective3_compare_all.py: imports changed only
- run_disordered_final.py: imports changed only
- check_materialfine_convergence.py: imports changed only
- build_disordered_mesh_buffer2_pml3_materialfine.py: unchanged
- validate_singlefile_solver.py: old-vs-new numerical equivalence test

Safe test procedure
1. Copy these files into the project root. Do not delete photoncs_fem yet.
2. Activate the femwell conda environment.
3. Run:
   python validate_singlefile_solver.py
4. Only continue to optimization if it ends with ALL CHECKS PASSED.

The validator checks Objectives 1, 2, 3, and the material-fine disordered solver.
